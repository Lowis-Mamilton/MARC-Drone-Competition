## 驗證範圍

這是通用教學四軸的模擬環境，實機機型與最終公告參數仍應更新至 `config/course.json`。真實 USB 手把、手機與防火牆須在使用現場確認；本次未以實體遙控器驗證。實體人員接觸與主觀裁判判定由裁判頁登錄。

受限測試環境中 Godot 會列出讀取 Windows 根憑證存放區失敗的診斷訊息；本機 HTTP／WebSocket、渲染與飛行測試均可正常完成。Scratch 的外部素材搜尋服務不屬於隨附離線資源；內建範例與 MARC 飛行積木可離線執行。
