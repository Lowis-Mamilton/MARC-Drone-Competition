手機與遙控器設定

目前啟動入口為 .runtime/studio/MARCDroneStudio.exe，或 npm.cmd start。

手機試飛

1. 手機與電腦連接同一個 Wi-Fi，開啟工作室上方「手機遙控」。
2. 選擇手機可到達的電腦 IP，掃描 QR Code。更換 Wi-Fi 後可按「重新整理電腦網路位址」。
3. 在電腦按「完成／關閉」，手機橫放。控制來源使用「自動選擇」或「手機」。
4. 將升降搖桿降到底，再按手機「起飛」。飛機升至 50 公分；升降搖桿會自動置中。
5. Mode 2：左手上／下控制升降、左／右控制轉向；右手控制前後左右。升降置中為懸停，方向搖桿放開即煞停。
6. 按「降落」安全降落；按「重置」停止飛行並返回停機坪，保留積木程式。

手機轉直、切至背景或失去連線會取消移動並安全降落。測試時電腦請保持工作室開啟。
若手機已配對但尚不能起飛，請關閉電腦上的設定頁、停止積木程式，並確認控制來源及競賽階段。

所有遙控設定

上方「遙控器設定」提供：

- 自動、鍵盤、指定 USB／藍牙遙控器、手機等來源。自動優先使用手機，其次遙控器，再來鍵盤。
- Mode 1、Mode 2、自訂四個通道；自訂時交換重複軸，確保每軸只控制一個通道。
- 四通道反向、死區及靈敏度。更改會自動保存，手機也會同步模式與映射。
- 即時雙搖桿監看、原始／校正數值、最小／中心／最大行程。
- 先擷取中心，再校正完整行程；校正按裝置 GUID 保存。油門採完整端點範圍，支援不回中的油門桿。
- 設定 JSON 匯入、匯出；無效數值或重複映射會拒絕匯入。
- 飛行或積木執行時鎖住設定。校正時不接受飛行；關閉設定會取消未完成校正。

MARC 使用定位懸停控制。Mode 2 的 USB 遙控器起飛前也須將油門降到底，起飛後移回中央以懸停。
Xbox A／PS × 起降，B／○ 切換視角，Menu／Options 重置。遙控器斷線會取消移動並安全降落。

競賽限制

自由練習可使用手機或 USB 遙控器。
正式「程式控制組」只接受積木；「遙控＋程式組」第一階段可遙控，第二階段使用積木。
正式比賽重置保留計時、得分及色卡判定；混合組第一階段不可重置。

驗證

已以手機尺寸瀏覽器及觸控事件驗證配對、起飛、前進、降落、重置、直向保護及 Mode 1 同步。
另有虛擬遙控器飛行及校正測試；實際 USB／藍牙硬體及手機跨 Wi-Fi 連線仍由使用者測試。
目前維持測試版，使用者測試通過後再打包。
