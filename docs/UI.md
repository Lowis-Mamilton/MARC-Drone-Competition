# 工作室介面與操作

上方工具列依序提供飛行、檔案、遙控與操作說明。標題列旁會顯示程式名稱及尚未儲存提示；右側顯示連線和程式執行狀態。

- 按「執行」開始積木程式，「停止」取消程式並懸停，「重置」回到停機坪並保留積木。正式比賽依原有重置規則判定。
- 編輯器右上方可選三個入門範例與兩個任務練習；修改後標示為自訂程式，載入其他範例前會提醒未儲存修改。取消會保留目前程式。
- 「工作區」可選積木＋場地、專心編程、全場飛行；中央分隔線可拖曳調整比例。視窗尺寸、工作區模式及分割比例會在關閉時保存。
- 「遙控器」設定控制來源、裝置校正、Mode 1／2、自訂通道、死區與靈敏度。「手機遙控」直接開啟配對頁。飛行前須完成並關閉設定。
- 編程區快捷鍵：F5 執行、Shift+F5 停止、Ctrl+R 重置、Ctrl+S 儲存、Ctrl+O 開啟。飛行畫面的原有 Space 起降、W/S、A/D、Q/E、R/F 與 C 視角鍵保留。

場地文字資訊每秒更新 10 次；遙控設定監看在頁面可見時每秒更新 20 次，行程校正仍逐幀採樣。原生視窗尺寸改以尺寸變更事件更新，嵌入完成後停止輪詢。飛行物理仍為每秒 120 次，渲染更新維持原流程。
