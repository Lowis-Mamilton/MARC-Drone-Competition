無人機積木入門

啟動 .runtime/studio/MARCDroneStudio.exe，或執行 npm.cmd start。左側編程，右側觀察飛機。

工具箱只有「無人機」、「流程」、「判斷與運算」。上方「執行」從綠旗開始跑積木；「停止」取消指令並懸停。「重置」會停止程式、將飛機放回停機坪並復原場地道具，保留積木程式。場地內的 Esc 為緊急停機。

啟動直接載入第一個範例，選單可切換。切換前請按「儲存 .sb3」保留修改。

| 簡單範例 | 積木順序 |
| --- | --- |
| ① 起飛與降落 | 起飛至 50 公分 → 懸停 2 秒 → 降落 |
| ② 前進再返航 | 起飛 → 沿 x 移動 60 公分 → 懸停 1 秒 → 沿 x 移動 −60 公分 → 降落 |
| ③ LED 變色 | 起飛 → 紅、綠、藍燈各亮 1 秒 → 白燈 → 降落 |

範例從停機坪中心 (40,160) 開始。每次測試前可按上方「重置」；正式比賽依規則限制重置，計時、得分及色卡判定保留，遙控加程式組第一階段不可重置。選單另有「讀色救援」與「穿越捷徑」任務練習；所有 .sb3 範例保存在 examples 資料夾。

距離為公分，高度指無人機底部離地高度。相對移動沿固定場地 x／y 軸，不隨機頭轉向。使用上方「儲存 .sb3／開啟 .sb3」保留及重開程式。

目前為內建編程測試版，待使用者測試通過後再打包。
